# NotebookLM Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get a transcript file into NotebookLM, ask it a question, land the results in `mind_forge/00 - Inbox/`, and prove a working promotion path from Inbox into properly filed `01 - Notes/` notes.

**Architecture:** Use the installed `notebooklm` CLI directly for notebook/source management (not documented in the local Claude Code skill, which assumes sources already exist), then the local skill's existing `import_sources.py`/`extract_passages.py`/`resolve_citations.py` scripts for the vault-write step, run with `cwd` set to `00 - Inbox/` so their `Path.cwd()`-relative output lands there instead of at vault root.

**Tech Stack:** `notebooklm-py` 0.7.3 (installed, CLI verified against its real `--help` output), Playwright + Chromium (installed), Python 3.13 (pyenv), existing `notebooklm` Claude Code skill scripts (unmodified).

## Global Constraints

- Vault root: `/Users/spencerduran/vaults/mind_forge`. This IS a git repo, but this plan does not require git commits: it creates vault content, not application code. No `git commit` steps in this plan; the user can commit vault changes on their own schedule.
- Do not modify anything under `~/.claude/plugins/marketplaces/personal-os-skills/skills/notebooklm/`. The local skill's scripts are used exactly as they exist.
- `notebooklm login` requires an interactive browser window and the user's own Google credentials. No task in this plan can complete that step programmatically; it's called out explicitly where it blocks.
- `import_sources.py` and `resolve_citations.py --output` both require a `--dashboard` argument (and `resolve_citations.py --output` also requires `--title`), used only to build a `related:` frontmatter wikilink. Per the approved spec, no dashboard file is created. Use the literal string `NotebookLM Imports` for every `--dashboard` value in this plan. The resulting `related:` link will be unresolved (shows as a "create note" link in Obsidian) until/unless someone creates that dashboard note later. This is acceptable: these files live in Inbox and either get promoted (frontmatter rewritten, this field dropped) or discarded.
- Commands that invoke `import_sources.py`, `extract_passages.py`, or `resolve_citations.py` must be run with the shell's working directory set to `/Users/spencerduran/vaults/mind_forge/00 - Inbox`, and must reference the scripts by their absolute path (`/Users/spencerduran/.claude/plugins/marketplaces/personal-os-skills/skills/notebooklm/scripts/...`), since the scripts resolve `Sources: ...`/`Notes/NotebookLM/...` output paths relative to `Path.cwd()`.
- Promoted notes go in flat `01 - Notes/` (no subfolders), matching mind_forge's existing convention.

**Goal:** Take a source or Q&A file staged in `00 - Inbox/Notes/NotebookLM/{slug}/` and file it properly into `01 - Notes/`, matching mind_forge's category/type/subjects conventions instead of the notebooklm skill's own defaults.

## Workflow Summary
1. Read the Inbox file and decide what kind of content it holds.
2. Pick the right category and reshape the content into that category's template.
3. Leave `subjects:` empty; keep NotebookLM's AI topics as a plain list instead.
4. Set `created:` to today, in `YYYY-MM-DD` format.
5. Write the new file into `01 - Notes/`, delete or keep the Inbox original.

---

## Step 1: Identify the content type

- **Source Guide for an interview** (frontmatter has `source_type: youtube`, `text`, or similar, and the body is a `## Source Guide` about a recorded conversation) -> go to Step 2a.
- **Source Guide for a meeting transcript** (the underlying source is a Zoom/meeting transcript, not an interview) -> go to Step 2b.
- **Q&A note** (frontmatter has `type: reference`, body is a resolved answer with citations) -> go to Step 2c.

## Step 2a: Promote an interview Source Guide -> Source Notes

Rewrite using this frontmatter and structure (matches `04 - System/Templates/Source Notes/talk.md`):

```yaml
---
category:
  - "[[Source Notes]]"
subjects: []
type: video
tags: []
created: YYYY-MM-DD
source:
speaker:
published:
duration:
---
# {Title: name the concept, not the source}

> [!quote] speaker
> {Best quote from the Source Guide or Cited Passages}

---
## Key Points
- {Turn the Source Guide's summary and topics into bullet points}

---
## Annotation

{Your own take. The Source Guide is raw material, not a substitute for this}
```

Fill `source:` with the original video URL (from the Inbox file's `url:` field), `speaker:` with names if known, `duration:` if known.

## Step 2b: Promote a meeting transcript Source Guide -> Meeting Notes

Rewrite using this frontmatter and structure (matches `04 - System/Templates/Meeting Notes/meeting.md`):

---
## Context

---
## Discussion

{Turn the Source Guide's summary into this section}

---
## Decisions

---
## Action Items
- [ ]
```

Pick a `type:` from Meeting Notes' allowed values (`1on1`, `planning`, `review`, `decision`, `brainstorm`) based on what the meeting actually was.

## Step 2c: Promote a Q&A note -> Reference

---

{The question asked}

---

NotebookLM Q&A against source: {source title}, notebook: {slug}

---
## Findings

{The resolved answer, wikilinks intact}

---
## Decision / Outcome

{One line: what you now know or plan to do with this}
```

## Step 3: Subjects and topics

Leave `subjects: []` for manual fill. It's mind_forge's controlled 16-item taxonomy (AI/Business/Entertainment/Health/History/Home/MLG/Music/Parenting/Philosophy/Politics/ProfDev/Productivity/Psychology/Theology/Trading), and NotebookLM's AI-extracted topics/keywords are open-ended and don't map onto it. Don't force them in. If the Inbox source file has a `### Topics` list or `topics:` frontmatter, carry those over as a plain bullet list under `## Annotation` (or equivalent) instead, e.g.:

```markdown
**NotebookLM topics:** risk-to-reward modeling, prop firm rule optimization, expected value calculation
```

- Save the new file into `01 - Notes/` (flat, no subfolders).
- Delete the Inbox original once you're satisfied the promoted version captures what matters, or leave it if you want to keep the raw AI-generated guide/citations around for reference.
